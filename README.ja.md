[![GitHub Pages](https://github.com/ttomohisa/htmlapps-interactive-guide-maker/actions/workflows/deploy-pages.yml/badge.svg)](https://github.com/ttomohisa/htmlapps-interactive-guide-maker/actions/workflows/deploy-pages.yml)

[English README](README.md)

Interactive Guide Maker は、文章・手順・注意・チェックリストなどのブロックを並べて手順書を作る Browser Kitty のツールです。完成した手順書は **1つの自己完結HTML** として保存でき、そのHTMLだけを相手へ渡してブラウザーで読めます。

**v1.0.0 は最初の正式版です。** PCではブロック間にマウスを置くと `+` からその位置へブロックを追加でき、下部のブロック追加もアイコン付きで整理しました。画像をドラッグすると挿入ラインで差し込み位置を確認でき、書き出したHTMLは後日そのまま再編集できます。

## 現在の範囲

v1.0.0では、v0.8.0までの開始画面・テンプレート・文書設定を維持しつつ、**編集途中の差し込み操作を短くするブロック間追加と位置指定画像ドロップ**を追加しました。完成HTMLそのものが再編集用ファイルでもあるため、別のプロジェクトファイルは不要です。

詳細は [APP_SPEC.md](APP_SPEC.md) を参照してください。

## 使い方

1. 空の手順書、操作手順、点検チェック、トラブル対応のいずれかから開始します。
2. 手順書タイトルを入力します。
3. **文章 / 画像 / 見出し / 手順 / 注意・補足 / チェックリスト / リンク / 折りたたみ / タブ / コード / 区切り** を追加します。PCではブロック間にマウスを置くと `+` が現れ、その位置へ追加できます。
4. 画像はファイル選択、Drag & Drop、クリップボード貼り付けで追加します。編集画面へドラッグすると挿入ラインが表示され、ドロップ位置へ差し込めます。
5. 必要に応じて代替テキスト、キャプション、表示幅、配置を設定します。
6. 補足説明は折りたたみ、OS別などはタブ、コマンドや設定値はコードブロックへ入力します。
7. タブ内には基本ブロックを複数配置できます。タブ内タブにはしません。
8. 各ブロックへ内容を入力します。手順番号は並び順に合わせて自動更新されます。
9. 必要に応じて **文書設定** から文字サイズ、本文幅、表示テーマを調整します。
10. 左側の「構成」から見出し・手順へ移動できます。
11. 左端のハンドルをドラッグするか「上へ / 下へ」で並べ替えます。
12. 必要に応じて Undo / Redo を使います。
13. 編集内容は端末内へ自動保存されます。
14. **HTMLを書き出す** を選び、ファイルサイズとファイル名を確認します。
15. 必要なら **プレビュー** で実際の閲覧状態を確認し、**HTMLを保存** します。
16. 保存後はファイル名とサイズが完了状態として表示されます。
17. 保存したHTMLはアプリ本体なしでブラウザーから閲覧できます。
18. 後から修正するときは **HTMLを開く** から、Interactive Guide Makerで書き出したHTMLを選びます。
19. 別の手順書を編集中の場合は置き換え確認後、復元された内容を編集して再度書き出します。

一般のHTMLを任意に編集する機能ではありません。ブラウザーのサイトデータを削除すると自動保存した下書きは消える場合がありますが、書き出したInteractive Guide Maker HTMLには再編集用データが含まれます。

## プライバシー

入力したタイトル、各ブロックの内容、読み込んだ画像はブラウザー内で処理します。ユーザーデータをサーバーへアップロードしません。アプリ実行時の外部通信も行わず、既定CSPでは `connect-src 'none'` を維持しています。

## 対応ブラウザー

- Edge 最新版

## 開発

Browser Kitty の最新単一HTMLテンプレートを基準にしています。

| ファイル | 用途 |
| --- | --- |
| `AGENTS.md` | Coding Agent向け実装ルール |
| `APP_SPEC.md` | アプリ仕様・範囲・受入条件 |
| `app.config.json` | アプリ情報とビルド設定 |
| `src/index.template.html` | 編集するアプリ本体ソース |
| `assets/favicon.svg` | favicon / 左上ブランドアイコンの正 |
| `components/` | Browser Kitty共通UI部品 |

v1.0.0でも外部ランタイム依存は追加していません。

## ビルド

Windows 10 / 11 で以下を実行します。

```bat
build-standalone.bat
```

ビルド後は `start-local.bat` で `dist/index.html` を既定ブラウザーから直接開けます。

テンプレートのビルド処理がPowerShell構文確認、リポジトリチェック、通常単一HTML生成、gzip自己展開版生成を行います。

生成物:

```text
dist/
├─ index.html
├─ index.self-extract.html
├─ dependency-manifest.json
├─ build-size-report.json
├─ self-extract-manifest.json
└─ .nojekyll
```

`dist/index*.html` は生成物です。直接編集せず `src/index.template.html` を修正して再ビルドします。

### 検証と配布用HTML

開発時の検証にはNode.js 24以降が必要です。通常ビルドではルートの `interactive-guide-maker.html` も読みやすい版と同じ内容に更新します。`-OutputPath` を指定したビルドではルート版を変更しません。リポジトリ検証はソース・読みやすい版・自己展開版・ルート版で同じ動作テストを実行し、配布物の一致も確認します。生成されたHTMLを直接編集せず、ソースを変更して再ビルドしてください。
