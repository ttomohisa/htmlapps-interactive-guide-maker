    使い方と注意事項

    基本操作

    1. 手順書タイトルを入力し、文章・画像・見出し・手順・注意・チェックリスト・リンクなどのブロックを追加します。
    2. 画像はファイル選択・ドラッグ＆ドロップ・クリップボード貼り付けで追加できます。各ブロックは複製・上下移動・削除・ドラッグ並べ替えに対応します。
    3. 編集内容は端末内へ自動保存されます。元に戻す / やり直すにも対応しています。
    4. 「HTMLを書き出す」でプレビューを確認し、単一HTMLとして保存します。

    プライバシー

    タイトル・本文・読み込んだ画像はブラウザー内で処理され、このアプリから外部サーバーへ送信されません。実行時の外部通信も行いません。

    注意事項

    • ブラウザーのサイトデータを削除すると、自動保存した下書きも消える場合があります。
    • 「HTMLを書き出す」から、閲覧機能を含む単一HTMLを保存できます。チェック状態は閲覧中のみ保持されます。
    • ダイアログを開いている間、元に戻す / やり直すは手順書に適用されません。Ctrl/Cmd+Sもダイアログを開き直しません。
    • ドラッグ操作が使いにくい場合は、各ブロックの上へ / 下へボタンでも同じ並べ替えができます。

    このアプリ本体は単一HTMLとして生成され、ローカルで直接開いて利用できます。
